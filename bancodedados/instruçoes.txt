Como criar o banco de dados de LOGIN:

1- Inicie uma conexão MySQL;
2- Clique com o botão DIREITO em cima de "localhost";
3- Vá em "Criar", e escolha "Banco de Dados" ;
4- Coloque o nome de "usuarios";
5- Após isso, novamente clique com o BOTÃO direito 
em cima de "localhost";
6- Vá em "Editor SQL";
7- Vá em "Novo Script SQL"
8- Dentro do Script, cole o seguindo a ordem:

-- Garante que você está usando o banco de dados correto
USE usuarios;

-- Cria a tabela 'Usuarios' com a coluna Senha como BINARY
CREATE TABLE Usuarios (
    ID INT AUTO_INCREMENT PRIMARY KEY,
    Nome VARCHAR(255) NOT NULL,
    Usuario VARCHAR(255) NOT NULL,
    Senha VARCHAR(255) BINARY NOT NULL
);

-- Insere as primeiras informações na tabela
INSERT INTO Usuarios (Nome, Usuario, Senha) VALUES ('Admin', 'admin', 'admin');

-- Verifica se os dados foram inseridos
SELECT * FROM usuarios;

9- Verificar se o banco de dados guardou os dados com:

SELECT * FROM usuarios;

10- Seu banco de dados do login está configurado.
